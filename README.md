# 資安值班室｜ISO 27001 入門

給零資安背景同仁的繁體中文互動教材。從虛構的市民健康講座名冊外露開始，練習辨識風險、決定措施、事件交接與查找稽核證據，最後用委外問卷案例檢查能否把判斷方法用在新情境。

## 使用方式

需安裝 Python 3。從專案根目錄啟動靜態伺服器，再開啟 <http://localhost:4173>。

```sh
python3 -m http.server 4173
```

程式使用原生 HTML、CSS 和 JavaScript modules，無需安裝前端套件。需透過 HTTP 開啟頁面。可交給靜態網站服務部署，入口為根目錄的 `index.html`，資源採相對路徑。

## 教材與進度

- 31 關，依 ISO/IEC 27001:2022 與 Amd 1:2024 逐條設計：開場 1 關、第 4 到 10 章的 25 條要求各 1 關、附錄 A 四個主題各 1 關，最後是獨立演練。
- 章與章依序解鎖，同一章內可自由選關；已完成的關卡可重讀解析。
- 每一關頁面下方有「條文對照」表：條文要求重點對上本關情境的做法（完成後顯示對應）。
- 「條文」頁列出 25 條要求的白話說明與通過狀態；「附錄 A」頁列出 93 項控制的白話說明，標示情境中練到的控制。
- 教材只放原創情境與白話摘要，不轉載標準原文。
- 進度、尚未完成的操作和提示使用狀況存在目前瀏覽器的 `localStorage`（`iso27001-learning-lab.v2`）。舊版 v1 進度會在首次載入時自動對應到新關卡。案件摘要可下載為 UTF-8 文字檔。
- 所有素材都是虛構的教學情境。練習紀錄不代表組織已實施控制或取得驗證。
- 檔案：`src/standard.js` 條文與附錄 A 索引，`src/lessons.js` 關卡教材，`src/progress.js` 進度與解鎖規則，`src/app.js` 介面。

## 開發檢查

用 Node.js 執行進度、沙盒判斷、匯出，以及條文覆蓋測試（每條要求與每個附錄 A 主題都必須有對應關卡）。

```sh
npm test
```
